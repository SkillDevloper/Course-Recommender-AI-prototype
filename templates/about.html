About Course Recommender AI

An intelligent system that combines traditional keyword-based methods with modern neural approaches to provide comprehensive course recommendations.

System Architecture

Frontend Layer
  • Flask Web Framework - Python backend server
  • Bootstrap 5 - Responsive UI components
  • RESTful API - JSON-based communication
  • AJAX/Fetch API - Dynamic content loading
Backend Layer
  • Flask-SQLAlchemy - Database ORM
  • SQLite Database - Data persistence
  • Joblib - Model serialization
  • Modular Design - Clean separation of concerns

Dataset Description

The system uses a curated dataset of 15 diverse courses across multiple departments. Each course includes:

Course Title

Descriptive course names

Department

Academic department categorization

Description

Detailed course descriptions

The dataset is extensible and can be easily replaced with real course catalogs from educational institutions.

ML Models Comparison

TF-IDF Model
How It Works:

Term Frequency-Inverse Document Frequency (TF-IDF) calculates the importance of words in documents relative to a collection.

Strengths:
  • Excellent for keyword matching
  • Fast computation
  • Interpretable results
  • Works well with technical terms
Limitations:
  • No semantic understanding
  • Can't handle synonyms well
  • Word order doesn't matter
  • Limited context awareness
Best for: Queries with specific technical terms and keywords
Neural Model
How It Works:

Uses Sentence-BERT (all-MiniLM-L6-v2) to create semantic embeddings and calculate cosine similarity between query and course descriptions.

Strengths:
  • Understands semantic meaning
  • Handles synonyms and paraphrasing
  • Captures context and relationships
  • Works with conceptual queries
Limitations:
  • Higher computational cost
  • Requires more training data
  • Less interpretable
  • Model size is larger
Best for: Natural language queries and conceptual understanding
Key Insight: The same query produces different results from each model because they approach understanding from different perspectives - keywords vs semantics.
